# Материалы практической работы №2, вариант 23

Тема: асинхронная генерация штрих-кодов EAN-13 в SVG через HTTP API.

Сдаваемый исходный код находится в корне этого Git-репозитория. Здесь лежат отчёт PDF/DOCX с титульником, пример SVG, результаты проверок, инструкция по пяти вопросам с фото и полный архив комплекта. `Учебная_копия_с_комментариями.zip` предназначена только для изучения; в ней есть обычные `#`-комментарии, запрещённые строгим аудитом исходников для сдачи.

Начать с `ИНСТРУКЦИЯ_ЗАЩИТЫ_ПО_ФОТО.md`. Результаты CI относятся к коммиту, указанному в `Проверки/verification.json`; для самого последнего состояния смотри вкладку GitHub Actions.
